## Focus

RPI Computer Science + Mathematics student with 5+ years of independent Android game modding and
runtime systems experience. My strongest work is below the editor layer: Unity IL2CPP, Cocos2d-x/Lua,
LSPosed/Xposed modules, native C++ hooks, metadata-based method and field resolution, emulator/root
tooling, movement and collision logic, game-loop modification, and runtime instrumentation.

Current role: **AI Model Evaluation Contractor through Handshake AI**.
